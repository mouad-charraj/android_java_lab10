# Lab 10 - Application Navigation Drawer (Mouad)

Ce projet consiste en une application Android utilisant un menu latéral (Drawer) pour naviguer entre plusieurs fragments de manière fluide.

## Structure du Projet
L'application est organisée autour d'une activité principale qui coordonne la navigation :
- **MainActivity** : Gère le DrawerLayout et la Toolbar personnalisée.
- **Fragments** : Trois sections distinctes (Fragment 1, Fragment 2, et une Liste interactive).
